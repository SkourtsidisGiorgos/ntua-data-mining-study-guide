# Ακολουθίες & Hidden Markov Models (HMM)

## Ακολουθίες (Sequences)

### Ορισμοί

**Ακολουθία:** Διατεταγμένη λίστα συμβόλων
```
S = <s₁, s₂, s₃, ..., sₙ>
```

**Υποακολουθία (Subsequence):**
- T είναι υποακολουθία του S αν μπορούμε να πάρουμε T διαγράφοντας στοιχεία από S
- Η **σειρά διατηρείται** αλλά τα στοιχεία ΔΕΝ χρειάζεται να είναι συνεχόμενα

**Παράδειγμα:**
```
S = <a, b, c, d, e>
Υποακολουθίες: <a, c, e>, <b, d>, <a>, <a, b, c, d, e>
ΟΧΙ υποακολουθία: <c, a> (λάθος σειρά)
```

---

## Hidden Markov Models (HMM)

### Τι είναι;
Στατιστικό μοντέλο όπου:
- Υπάρχουν **κρυφές καταστάσεις** (hidden states)
- Παρατηρούμε **σύμβολα** (observations) που εξαρτώνται από την τρέχουσα κατάσταση

### Συστατικά HMM

| Σύμβολο | Περιγραφή |
|---------|-----------|
| S = {s₁, s₂, ..., sₙ} | Σύνολο καταστάσεων |
| Σ = {σ₁, σ₂, ..., σₘ} | Σύνολο συμβόλων (observations) |
| Π = {π₁, π₂, ..., πₙ} | Αρχικές πιθανότητες (initial state probabilities) |
| A = [aᵢⱼ] | Πίνακας μετάβασης (transition probabilities) |
| B = [bⱼ(σₖ)] | Πίνακας εκπομπής (emission probabilities) |

### Παράμετροι

**Initial Probabilities (Π):**
```
πᵢ = P(q₁ = sᵢ)  — Πιθανότητα να ξεκινήσουμε από κατάσταση sᵢ
```

**Transition Probabilities (A):**
```
aᵢⱼ = P(qₜ₊₁ = sⱼ | qₜ = sᵢ)  — Πιθανότητα μετάβασης από sᵢ σε sⱼ
```

**Emission Probabilities (B):**
```
bⱼ(σₖ) = P(oₜ = σₖ | qₜ = sⱼ)  — Πιθανότητα εκπομπής συμβόλου σₖ στην κατάσταση sⱼ
```

## Ερώτηση Εξέτασης 2025 (Q12)

**Ερώτηση:** Ποια πρόταση για τα HMM είναι σωστή;

**Επιλογές:**
a) Οι εκπαιδεύσιμες παράμετροι ενός HMM είναι οι αρχικές πιθανότητες και οι πιθανότητες μετάβασης.

b) Τα HMM μπορούν να χρησιμοποιηθούν για clustering, classification και outlier detection.

c) Ο αλγόριθμος Baum-Welch είναι αλγόριθμος expectation-maximization.

d) Ο αλγόριθμος Viterbi καθορίζει την πιο πιθανή ακολουθία καταστάσεων για την παρατηρούμενη ακολουθία.

**Απάντηση:**
- **(a)** είναι **ΛΑΘΟΣ** - εκπαιδεύονται ΚΑΙ οι emission probabilities (B)
- **(c)** είναι **ΣΩΣΤΟ** - Baum-Welch είναι EM algorithm
- **(d)** είναι **ΣΩΣΤΟ** - Viterbi βρίσκει most likely state sequence

## Βασικά Προβλήματα HMM

### 1. Evaluation Problem
**Ερώτηση:** Δοθέντος μοντέλου λ και ακολουθίας O, ποια είναι η P(O|λ);
**Αλγόριθμος:** Forward Algorithm

### 2. Decoding Problem
**Ερώτηση:** Ποια είναι η πιο πιθανή ακολουθία καταστάσεων;
**Αλγόριθμος:** Viterbi Algorithm

### 3. Learning Problem
**Ερώτηση:** Ποιες παράμετροι μεγιστοποιούν P(O|λ);
**Αλγόριθμος:** Baum-Welch (EM)

## Forward Algorithm (Υπολογισμός Πιθανότητας Ακολουθίας)

### Ορισμός Forward Variable
```
αₜ(i) = P(o₁, o₂, ..., oₜ, qₜ = sᵢ | λ)
```

### Βήματα

**1. Αρχικοποίηση (t=1):**
```
α₁(i) = πᵢ × bᵢ(o₁)
```

**2. Επαγωγή (t > 1):**
```
αₜ(j) = [Σᵢ αₜ₋₁(i) × aᵢⱼ] × bⱼ(oₜ)
```

**3. Τερματισμός:**
```
P(O|λ) = Σᵢ αₜ(i)
```

## Λυμένο Παράδειγμα HW2: Υπολογισμός P(V|λ)

### Δεδομένα HMM

**Καταστάσεις:** S = {s₁, s₂}

**Σύμβολα:** Σ = {a, b, c}

**Αρχικές πιθανότητες:** Π = {0.2, 0.8}

**Πίνακας μετάβασης (A):**
```
A = | 0.x    1-0.x |
    | 0.x    1-0.x |
```
(Έστω x=4 → A = [0.4, 0.6; 0.4, 0.6])

**Πίνακας εκπομπής (B):**
```
B = | 0.5  0.5  0   |  ← s₁: P(a)=0.5, P(b)=0.5, P(c)=0
    | 0.5  0    0.5 |  ← s₂: P(a)=0.5, P(b)=0, P(c)=0.5
```

**Ακολουθία:** V = {b, c, a}

### Λύση - Βήμα προς Βήμα

**Βήμα 1: Αρχικοποίηση (o₁ = b)**

```
α₁(s₁) = π₁ × b₁(b) = 0.2 × 0.5 = 0.1
α₁(s₂) = π₂ × b₂(b) = 0.8 × 0 = 0
```

**Βήμα 2: Επαγωγή για o₂ = c**

```
α₂(s₁) = [α₁(s₁) × a₁₁ + α₁(s₂) × a₂₁] × b₁(c)
       = [0.1 × 0.4 + 0 × 0.4] × 0
       = 0.04 × 0
       = 0

α₂(s₂) = [α₁(s₁) × a₁₂ + α₁(s₂) × a₂₂] × b₂(c)
       = [0.1 × 0.6 + 0 × 0.6] × 0.5
       = 0.06 × 0.5
       = 0.03
```

**Βήμα 3: Επαγωγή για o₃ = a**

```
α₃(s₁) = [α₂(s₁) × a₁₁ + α₂(s₂) × a₂₁] × b₁(a)
       = [0 × 0.4 + 0.03 × 0.4] × 0.5
       = 0.012 × 0.5
       = 0.006

α₃(s₂) = [α₂(s₁) × a₁₂ + α₂(s₂) × a₂₂] × b₂(a)
       = [0 × 0.6 + 0.03 × 0.6] × 0.5
       = 0.018 × 0.5
       = 0.009
```

**Βήμα 4: Τερματισμός**

```
P(V|λ) = α₃(s₁) + α₃(s₂) = 0.006 + 0.009 = 0.015
```

**Απάντηση: P({b,c,a}) = 0.015 ή 1.5%**

## Viterbi Algorithm (Πιο Πιθανό Path)

### Ορισμός
```
δₜ(j) = max_{q₁,...,qₜ₋₁} P(q₁, ..., qₜ₋₁, qₜ = sⱼ, o₁, ..., oₜ | λ)
```

### Βήματα

**1. Αρχικοποίηση:**
```
δ₁(i) = πᵢ × bᵢ(o₁)
ψ₁(i) = 0
```

**2. Επαγωγή:**
```
δₜ(j) = max_i [δₜ₋₁(i) × aᵢⱼ] × bⱼ(oₜ)
ψₜ(j) = argmax_i [δₜ₋₁(i) × aᵢⱼ]
```

**3. Τερματισμός:**
```
P* = max_i δₜ(i)
q*ₜ = argmax_i δₜ(i)
```

**4. Backtracking:**
```
q*ₜ₋₁ = ψₜ(q*ₜ)
```

### ΣΗΜΑΝΤΙΚΟ: Διαφορά από Forward
- **Forward:** Αθροίζουμε (Σ) - όλα τα πιθανά paths
- **Viterbi:** max - το καλύτερο path

---

## Σύγκριση Forward vs Viterbi

| | Forward | Viterbi |
|---|---------|---------|
| Σκοπός | P(O\|λ) | Best state sequence |
| Πράξη | Σ (sum) | max |
| Αποτέλεσμα | Πιθανότητα | Path + πιθανότητα |

---

## Baum-Welch Algorithm

**Τι κάνει:** Μαθαίνει τις παραμέτρους (A, B, Π) από δεδομένα

**Είδος:** Expectation-Maximization (EM) algorithm

**Βήματα:**
1. **E-step:** Υπολογισμός expected state occupancies
2. **M-step:** Re-estimation παραμέτρων
3. Επανάληψη μέχρι σύγκλιση

---

## Συχνά Λάθη στις Εξετάσεις

### 1. Ξεχνάω τον emission probability
```
❌ αₜ(j) = Σᵢ αₜ₋₁(i) × aᵢⱼ
✓  αₜ(j) = [Σᵢ αₜ₋₁(i) × aᵢⱼ] × bⱼ(oₜ)  ← ΜΗΝ ΞΕΧΝΑΣ το b!
```

### 2. Σύγχυση Forward vs Viterbi
- Forward: **ΑΘΡΟΙΣΗ** όλων των paths
- Viterbi: **ΜΕΓΙΣΤΟ** path

### 3. Λάθος διαστάσεις πινάκων
- A: n×n (καταστάσεις × καταστάσεις)
- B: n×m (καταστάσεις × σύμβολα)
- Π: n×1 (αρχικές πιθανότητες)

### 4. Υποακολουθία vs Substring
- **Subsequence:** Διατηρεί σειρά, ΟΧΙ συνεχόμενα
- **Substring:** Συνεχόμενα στοιχεία

```

║                    HMM CHEAT SHEET                               ║
╠══════════════════════════════════════════════════════════════════╣
║ ΠΑΡΑΜΕΤΡΟΙ:                                                      ║
║   Π = αρχικές πιθανότητες (initial)                              ║
║   A = πιθανότητες μετάβασης (transition)                         ║
║   B = πιθανότητες εκπομπής (emission)                            ║
╠══════════════════════════════════════════════════════════════════╣
║ FORWARD ALGORITHM (Πιθανότητα ακολουθίας):                       ║
║   Init:  α₁(i) = πᵢ × bᵢ(o₁)                                     ║
║   Step:  αₜ(j) = [Σᵢ αₜ₋₁(i) × aᵢⱼ] × bⱼ(oₜ)                     ║
║   End:   P(O|λ) = Σᵢ αₜ(i)                                       ║
╠══════════════════════════════════════════════════════════════════╣
║ VITERBI ALGORITHM (Καλύτερο path):                               ║
║   Init:  δ₁(i) = πᵢ × bᵢ(o₁)                                     ║
║   Step:  δₜ(j) = max_i[δₜ₋₁(i) × aᵢⱼ] × bⱼ(oₜ)                   ║
║   End:   P* = max_i δₜ(i), backtrack με ψ                        ║
╠══════════════════════════════════════════════════════════════════╣
║ ΣΗΜΑΝΤΙΚΟ:                                                       ║
║   Forward: Σ (sum) → P(O|λ)                                      ║
║   Viterbi: max → best path                                       ║
║   ΜΗΝ ΞΕΧΝΑΣ το bⱼ(oₜ) στο τέλος!                                ║
╚══════════════════════════════════════════════════════════════════╝
```
